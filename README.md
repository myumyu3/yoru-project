# 🌙 Yoru Project

> ファンタジーの選択式アドベンチャー「ヨル」シリーズ。  
> ブラウザだけで遊べます。インストール不要。

---

## 🎮 作品一覧

### 🕯️ ヨルと灰のうた

**[▶ ブラウザですぐ遊ぶ](https://myumyu3.github.io/yoru-project/yoru_game.html)**

まちに、音もなく「灰」がふりはじめた。  
あびたものが、すこしずつ「しずか」になっていく。  
ある朝、ともだちのモモが手紙をのこして、灰の森へ消えた。  
ちいさなヨルは、小さなほうきを手に取り、歩きはじめる。

> ちいさなヨルが、灰のふる森で、ともだちと、名前をさがす話。

- 全 60 場面・選択式アドベンチャー
- エンディング 4 種 + おまけ
- イラスト & BGM つき

### ⛰️ ヨルと星の鐘　第三章「鐘の山」

**[▶ ブラウザですぐ遊ぶ](https://myumyu3.github.io/yoru-project/yoru2z_game.html)**

だれも帰ってこないという、鐘の山。  
ヨルとモモは、あつめたかけらをふところに、さいごののぼり坂へむかう。  
山には、やぶってはいけない「ならわし」がある——山では、名まえをやらない。

> シリーズ完結編。いちばんしずかで、いちばんこわい章。

- 全 110 場面・独立完結
- エンディング多数——TRUE END の先に、シリーズの「むこうがわ」が待つ
- BGM つき・チェックポイントあり

### 🌌 ヨルと星の鐘　統合版（全三章とおしあそび）

**[▶ ブラウザですぐ遊ぶ](https://myumyu3.github.io/yoru-project/yoru2w_game.html)**

第一章「まちと夜行列車」から、完結編の第三章「鐘の山」までを、

> シリーズ三部作を、まるごとひと旅で。

- 全 337 場面（全三章＋章とびら）・かきおろしの新タイトル絵
